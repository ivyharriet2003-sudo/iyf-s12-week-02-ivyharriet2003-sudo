## Overview
Week 1 portfolio styled with CSS, Flexbox and Grid, mobile-first.

## Features
- Reset with box-sizing: border-box
- CSS variables for color and typography
- Flexbox navigation
- Grid projects: 1 column mobile, 2 tablet, 3 desktop
- Media queries min-width
- Hover and focus states with visible outline

## Structure
- index.html, about.html, projects.html, contact.html
- styles.css (one stylesheet)
- box-model-practice.html (Task 3.2)
- daily-challenges/

## Tested
320px, 768px, 1024px, 1440px - no sideways scroll on live site.

## Lessons Learned
I learned how box-sizing border-box makes width include padding and border, how to make mobile-first with base styles for phone and media queries for bigger screens, and how Grid changes columns from 1 to 3. I also fixed focus states so keyboard users can see where they are.
